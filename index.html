About This Tool

Europe-wide numerical weather prediction (NWP) model visualizer using the Open-Meteo API. Features include:

  • Europe-wide interpolated spatial field rendering
  • Animated wind particle flow visualization
  • Meteorological color scales (temperature, precipitation, wind, humidity, pressure, cloud cover)
  • GFS vs ECMWF model comparison
  • Professional meteogram (click any point)
  • Wind barb notation
  • Forecast hour animation

Data source: Open-Meteo API (CC BY 4.0)
